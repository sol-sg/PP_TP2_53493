Trabajo Práctico 2 – Programación Orientada a Objetos en Java

Materia: Paradigmas de Programación
UTN – Facultad Regional Mendoza

Descripción

Proyecto correspondiente al Trabajo Práctico N.º 2, desarrollado en Java utilizando IntelliJ IDEA.

El proyecto consiste en un sistema de gestión de eventos universitarios, donde se implementan conceptos de Programación Orientada a Objetos y recursos avanzados de Java.

Durante el desarrollo se trabajó con:

Encapsulamiento, herencia y polimorfismo.
Interfaces y clases abstractas.
Excepciones y manejo de errores.
Serialización y persistencia de objetos.
Colecciones y genéricos.
Wildcards y métodos parametrizados.
Clases y objetos relacionados mediante asociaciones, agregación y composición.

El proyecto se encuentra implementado hasta el Ejercicio 3 del Trabajo Práctico 2.

Ejecución

El programa puede ejecutarse desde la clase `App` en IntelliJ IDEA.

El repositorio incluye el código fuente completo y una captura de la salida por consola de una ejecución del programa.
